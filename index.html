01. Smart Home Energy Management System

A locally hosted energy monitoring and appliance-control platform built around a Raspberry Pi backend.

Back to projects ↑

Project scope

A smart home prototype that collects appliance and main-supply data, stores usage records locally, exposes API services, and provides a dashboard for monitoring, billing insight, and appliance control.

My role

Results

Computer Vision / Edge AI · Feb 2025 - Sep 2025

04. Egg Crack Detection System

Raspberry Pi 5 conveyor prototype using camera capture and CNN inference to classify cracked and intact eggs.

Back to projects ↑

Project scope

A low-cost automated quality inspection prototype intended for small and medium-scale egg handling environments where manual inspection is slow and inconsistent.

My role

Worked on the integrated system flow combining IR triggering, conveyor stopping, image capture, model inference and LED indication. The model was trained using transfer learning and deployed locally on the Raspberry Pi.

Technical implementation

  • IR sensor detects an egg at the inspection point and triggers the timed capture sequence.
  • Conveyor pauses briefly to stabilize the egg before image capture through an IMX219 camera.
  • A VGG16-based CNN classifies the captured image as cracked or intact; GPIO-controlled LEDs show the output.

Results

  • Model assessment reported 72.3% accuracy, 76.2% precision and 66.7% recall on the validation set.
  • Prototype testing across 124 captured images reached 78.2% overall classification accuracy.
  • The system achieved roughly 0.8 s inference time per image in the prototype workflow.

05. Semantic-Aware Image Compression

OCR-guided DCT compression that preserves text readability while compressing background regions more aggressively.

Back to projects ↑

Project scope

A DSP project exploring region-aware compression for images that contain text, where readability matters more than uniform visual quality.

My role

Implemented the semantic pipeline: OCR-based text localization, block-level classification, 8x8 DCT processing, text-preserving coefficient handling and background vector quantization.

Technical implementation

  • OCR output was converted into a text mask and aligned with 8x8 DCT blocks.
  • Text blocks were preserved with higher fidelity while background blocks were compressed using LBG-trained vector quantization.
  • Results were compared against uniform compression behaviour using visual and numerical quality observations.

Results

  • Improved text readability compared with uniform compression at similar compression intent.
  • Text-region quality was prioritized while retaining useful background compression.
  • The project demonstrated semantic bit allocation using classical DSP tools rather than a black-box codec.

Robotics / Control · Jan 2026 - Feb 2026

06. Line Follower Robot with Fuzzy Logic Control

ESP32 differential-drive robot using a five-sensor IR array and Sugeno-style fuzzy rule mapping for line tracking.

Back to projects ↑

Project scope

A mobile robotics and controls project focused on replacing simple threshold-based steering with fuzzy rule-based motor control.

My role

Worked on robot layout, sensor integration, rule mapping, motor-driver integration and practical tuning on curved track sections.

Technical implementation

  • Five IR sensor states were mapped into steering behaviour using a zero-order Sugeno-style fuzzy rule base.
  • The ESP32 generated left/right motor commands through a TB6612FNG dual motor driver.
  • Track tests were used to tune behaviour around curves and junctions.

Results

  • Reduced abrupt steering compared with basic on/off line-following logic.
  • Demonstrated robust tracking on a lab-built path with turns and transitions.
  • Produced a compact embedded robotics prototype from circuit to motion testing.
