# Agsharan Sakthitharan Portfolio Site

This is a static GitHub Pages-ready portfolio website.

## Deploy on GitHub Pages

1. Unzip this package.
2. Copy everything inside this folder into the root of your GitHub Pages repository.
3. Commit and push the files.
4. In GitHub, go to **Settings -> Pages**.
5. Set source to the main branch and root folder.
6. Wait for GitHub Pages to publish the site.

## Important privacy note

This website does **not** include the original university submission reports, DOCX files, PDF reports, declarations, appendices, or private code. It only uses rewritten portfolio content, selected project visuals, recreated public diagrams, and the public CV PDF.

## Update links

Edit `index.html` if you want to change LinkedIn, GitHub, email, project links or section text.
